# Pixora n8n Automation Internship

## Overview

This repository contains three n8n automation projects developed as part of the Pixora n8n Automation Internship.

The projects demonstrate beginner, intermediate, and advanced business automation concepts using n8n.

---

## Projects

### Project 1 — Lead Capture Automation

**Workflow:**

Website/Form → Webhook → Validation → Google Sheets → Business Notification → Customer Auto Reply

### Features

* Lead capture
* Google Sheets CRM
* Phone validation
* Business-owner notification
* Customer confirmation
* Error handling
* Execution logging

---

### Project 2 — AI WhatsApp Auto-Reply Bot

**Workflow:**

WhatsApp → Message Processing → Gemini AI → Response → WhatsApp → Google Sheets

### Features

* AI-powered customer replies
* Personalized responses
* FAQ automation
* Conversation logging
* Human escalation
* AI error handling

---

### Project 3 — End-to-End Business Automation

**Workflow:**

Lead Capture → CRM → Day 0 Follow-up → Day 3 Follow-up → Day 5 Follow-up → Weekly Report

### Features

* Automated lead management
* AI-personalized follow-ups
* CRM status tracking
* Day 0/3/5 follow-up automation
* Weekly analytics
* Automated reporting
* Modular workflow architecture

---

## Technologies

* n8n
* Google Sheets
* Gmail
* Webhooks
* Gemini/OpenAI API
* WhatsApp/WAHA
* JavaScript
* REST APIs

---

## Security

API keys and credentials are not stored in this repository.

Credentials should be configured through n8n's credential manager.

---

## Testing

Each workflow should be tested using real form submissions or real trigger events rather than only manually executing individual nodes.

---

## Documentation

Each workflow contains node-level documentation and a workflow architecture diagram explaining the purpose of the automation.
